# Как применить исправление

В архиве исправлен код, но действующий бот на GitHub/сервере пока использует
старые файлы. Обновление нужно загрузить туда, где он запускается.

## Если бот запускается через GitHub Actions

1. Распакуй этот ZIP на компьютере.
2. Открой свой репозиторий `isakov17951/tvbrics-monitor-bot` на GitHub.
3. На вкладке **Code** открой **Add file → Upload files**.
4. Загрузи в корень репозитория исправленные файлы:
   `scraper.py`, `config.py`, `db.py`, `bot.py`, `search_once.py`,
   `delivery.py`, `requirements.txt`, `README.md`, `UPDATE_RU.md`,
   `.env.example` и папку `tests` целиком.
   Загружай именно файлы и `tests`, а не наружную папку `tvbrics-monitor-bot-main`.
5. Сохрани изменения кнопкой **Commit changes**.
6. Обязательно обнови `.github/workflows/search.yml` содержимым одноимённого
   файла из архива. Можно открыть этот файл в GitHub, нажать значок карандаша,
   заменить его содержимое и сохранить. В новой версии добавлены проверки
   и сохранение базы после частичных сбоев; установка Chromium сохранена.
7. Не заменяй существующий `seen_news.db` файлом из скачанного архива:
   в репозитории уже может быть более свежая история. В архиве сохранена
   исходная база из присланной копии. Настроенные GitHub Secrets сохраняются
   при замене файлов — их не нужно вводить заново.
8. Открой **Actions → Поиск новостей иранских партнёров → Run workflow**,
   выбери ветку, куда загрузил изменения, и запусти.
9. После успешного запуска подборка придёт в Telegram. Если запуск красный,
   открой его и посмотри шаг **Поиск** или **Сохранить базу**.

В workflow уже указано прежнее расписание: ежедневно в 09:00 по Москве.
Секреты `BOT_TOKEN` и `CHAT_ID` должны быть заполнены в настройках репозитория.
Если расписание ранее было отключено GitHub, включи workflow на странице Actions.

## Если бот работает на компьютере или сервере

1. Останови старый процесс бота.
2. Сохрани свои действующие `.env` и `seen_news.db`.
3. Замени файлы кода и папку `tests` файлами из архива, сохранив действующие
   `.env` и базу в папке бота.
4. В папке бота выполни:

```sh
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m unittest discover -s tests -v
python search_once.py --dry-run
```

5. Если проверка завершилась без ошибок, запусти:

```sh
python bot.py
```

6. В Telegram нажми **🔍 Запустить поиск**.

Для проверки сайта без Telegram можно запускать `--dry-run` даже без токена.

Если бот сообщит, что сайт ограничил доступ или запросил проверку браузера,
это отдельная проблема доступа. Поиск в этом случае остановится, а запуск
Actions станет красным. Сообщение «новостей нет» при таком сбое не появится.
Для постоянного автоматического сбора при блокировке нужно согласовать доступ
с администрацией TV BRICS.

# TV BRICS — бот поиска новостей иранских партнёров

Telegram-бот с кнопкой «Запустить поиск». Обходит tvbrics.com как обычный
пользователь (управляемый браузер Chromium), фильтрует ленту по стране Иран,
листает кнопкой «ЕЩЕ» вглубь на 10 дней, открывает статьи и оставляет только
те, где есть ссылка на иранского партнёра. Найденное запоминает в базе и
второй раз не показывает.

## Файлы

| Файл | Что делает |
|---|---|
| `bot.py` | Telegram-бот, кнопка, формат вывода |
| `scraper.py` | Обход сайта (Playwright, имитация пользователя) |
| `config.py` | Все настройки: ПАРТНЁРЫ, языки, селекторы, паузы |
| `db.py` | База уже найденных новостей (SQLite) |
| `.env.example` | Шаблон для токена |

## Установка (один раз)

1. Установи Python 3.10+ с python.org (на Windows при установке отметь
   галочку "Add Python to PATH").
2. В папке проекта открой терминал и выполни:
   ```
   pip install -r requirements.txt
   playwright install chromium
   ```
3. Скопируй `.env.example` в файл с именем `.env` и вставь туда токен
   от @BotFather:
   ```
   BOT_TOKEN=123456:ABC-DEF...
   ```
4. Открой `config.py` и заполни словарь `PARTNERS` доменами партнёров
   (внутри есть пример, как добавлять).

## Запуск

```
python bot.py
```

Окно терминала держи открытым — пока оно открыто, бот живёт.
В Telegram: найди своего бота → `/start` → кнопка «🔍 Запустить поиск».

## Отладка

Если бот «не видит» элементы на какой-то языковой версии — в `config.py`
поставь `HEADLESS = False`: откроется настоящее окно браузера, и будет
видно, что именно бот делает и где спотыкается.

## GitHub

```
git init
git add .
git commit -m "TV BRICS Iran news bot"
```
Дальше создай репозиторий на github.com и запушь по их подсказке.
Файлы `.env` (токен) и `*.db` (база) в репозиторий не попадут — они
закрыты через `.gitignore`. Так и должно быть.

## Что осталось проверить (известные допущения)

1. Адреса лент языковых версий (`/en/news/` и т.д.) — гипотеза.
2. data-id Ирана `784184` на других языках — гипотеза (скорее всего общий).
3. Формат даты `ДД.ММ.ГГ` на других языках — гипотеза.

План проверки: открыть английскую версию, повторить трюк с DevTools
(меню стран → data-id Ирана → формат даты на карточке) и сверить.
